| [Software para búsqueda y recomendación de recetas de cocina](https://github.com/almondoryluis/iCook) | Proyecto de Ingeniería de Software I, FICCT-UAGRM. Desarrollado individualmente. Mi aporte aporte principal fue el investigar y aplicar: [búsqueda de recetas en la Web mediante una API](https://github.com/almondoryluis/iCook/blob/main/Servidor/api/recetas/busqueda/web_search_api.py#L19), [extracción de recetas mediante web scraping](https://github.com/almondoryluis/iCook/blob/main/Servidor/api/recetas/extraccion/controllers.py#L423), [obtención de text embeddings](https://github.com/almondoryluis/iCook/blob/main/Servidor/api/recetas/recomendacion/text_embeddings_api.py#L18) de recetas de cocina usando la API de Google Gemini, [llenado y consulta de una base datos vectorial](https://github.com/almondoryluis/iCook/blob/main/Servidor/api/recetas/recomendacion/vector_database_api.py#L23) ([Pinecone AI](https://www.pinecone.io/)) para realizar la búsqueda y recomendación de recetas, el desarrollo de una [API REST en Django](https://github.com/almondoryluis/iCook/tree/main/Servidor) y una [aplicación móvil cliente en Flutter](https://github.com/almondoryluis/iCook/tree/main/Cliente). |
